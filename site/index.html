HWatch

Self-hosted NAS media subscription, downloader and Plex TV library manager — powered by Go, SQLite, aria2 and Vue/TypeScript.

View on GitHub Quick start

Features

📡

Creator subscriptions

Full-pagination subscriptions build a complete baseline, then auto-download new works.

⬇️

Persistent downloads

aria2 / wget engines, pause & resume, resumable transfers, 429 backoff with live speed.

🎬

Plex TV library

tvshow.nfo, per-episode NFO, posters and thumbnails written into your existing media root.

🧩

Platform adapters

Rule34Video and Hanime1 today, behind a unified adapter interface for new sources.

🔐

Auth & audit

Admin sessions with CSRF, structured audit log, task history, notifications and health checks.

🌐

WebAI translation

Safe JSON export of titles/tags with source-hash verification and re-import.

Quick start

Replace the NAS path in compose.yaml with your Plex media directory, then:

# docker compose
/path/on/nas/Plex-TV:/media
docker compose up -d --build
# open
http://NAS-IP:8787

Or run from source (Go 1.24, Node.js, aria2, FFmpeg):

npm install && npm run build
aria2c --enable-rpc=true --daemon=true
go run ./cmd/r34watch
  • SQLite + aria2 session in the data directory
  • Plex and HWatch read the same video files — no duplicate copy
  • Create an admin account on first visit
